# Demo de tres minutos

1. (0:00–0:30) Presentar QuantumByte y el aviso de prototipo independiente: catálogo y reservas ficticias; no son datos institucionales.
2. (0:30–1:20) Mostrar las tres salas, fecha y franja; distinguir disponibilidad administrativa de ocupación física. Una lectura desconocida o sin detecciones no demuestra una sala vacía.
3. (1:20–2:10) Mostrar búsqueda y revisión manual de reserva; confirmar solo si se ha preparado una base aislada de demostración. Presentar Secretaría como perfil visual sin autenticación real.
4. (2:10–3:00) Mostrar el asistente y explicar que propone y requiere revisión humana. Si el proveedor no está configurado, usar búsqueda manual. Si no hay sensor autorizado y vigente, mostrar desconocido; una grabación es una muestra, no ocupación actual.

Contingencia: tener abiertos el catálogo y esta guía; no afirmar conexión, precisión o rendimiento que no se hayan verificado durante el ensayo.
